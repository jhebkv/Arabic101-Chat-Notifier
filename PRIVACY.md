# Privacy Policy for Arabic101 Chat Assistant & Notifier

**Effective Date:** September 3, 2026

## 1. Information Collection

This extension **does not collect, store, or transmit any personal information**.

The extension only:
- Reads chat messages already visible on the Arabic101 dashboard to display them in the floating widget
- Loads user profile images from the Arabic101 dashboard
- Plays notification sounds from the Arabic101 server
- Saves your theme preference (light/dark mode) locally in your browser using `chrome.storage`

## 2. Data Usage

All data processing occurs **locally in your browser**. No data is:
- Sent to external servers (except the Arabic101 dashboard API for sending/receiving messages)
- Stored permanently
- Shared with third parties
- Used for tracking or analytics

## 3. Permissions

| Permission | Purpose |
|------------|---------|
| `storage` | Saves your theme preference locally |
| `notifications` | Shows desktop alerts when new messages arrive |
| Host permission (`dashboard.arabic101.org/*`) | Required to access chat data from the Arabic101 dashboard |

## 4. Third-Party Services

This extension does not use any third-party analytics, tracking, or advertising services.

## 5. Your Rights

You can:
- Disable notifications at any time in your browser settings
- Uninstall the extension to remove all locally stored data
- Contact the developer with any privacy concerns
